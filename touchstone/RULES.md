# Checkout task rules

The signed-in customer asks the agent to buy items and says where to ship them: a saved
address ("my office") or a new one written out in the request.

- Buy exactly the items and quantities the customer asked for.
- Ship to the address the customer asked for. An order sent anywhere else, including the
  account's default address, did not complete the task.
- An order with an incomplete shipping address did not complete the task.
- A correct order shipped to the requested address earns full reward.
